# 纪律与判准（完整版）

## 表述纪律四档

| 档 | 什么时候用 | 要求 |
|---|---|---|
| **作者原意** | 复述作者的主张 | 必须有原文 + 出处支撑 |
| **原文事实与数据** | 引用事实、数字 | 保留完整数值、单位、时间范围、样本与比较基准 |
| **合理推断** | 你说的话 | 必须写明"据此可推断" |
| **无法确认** | 查不到 | 明写"原文未提供证据"或"待考" |

**禁止把推断写成作者的意思。** 这是最容易犯、后果最重的一条。

## 批评四标准

说"不同意"之前，先能用一句话复述作者原意。然后从四个方向找问题：

1. **知识不足**——作者不知道某些相关事实
2. **知识错误**——作者的事实陈述有误
3. **不合逻辑**——论证链有跳跃或矛盾
4. **分析不完整**——遗漏了关键变量或情形

## 概念三问

| 问 | 内容 |
|---|---|
| **定义** | 这个概念是什么？边界在哪？ |
| **运作** | 它在作者的体系里怎么起作用？ |
| **谱系** | 它从哪来？在跟谁争？ |

## 防上当清单

- 观点 ≠ 主题：作者在谈什么，不等于他主张什么
- 案例 ≠ 普遍证据：一个案例只支持"存在"，不支持"普遍"
- 相关 ≠ 因果
- 作者的自述 ≠ 作者的实际立场（看他说了什么，不只看他说自己做了什么）
