# 五模式精简默认版

> **仅当目标库没有自己的 `_templates/` 时才用本文件。**
> 若目标库有模板，一律以库内模板为准。

## A · 单文件笔记（1–2 千字）

一段话说清这本书在讲什么 → 3–5 个要点 → 值得记住的两三句原文 → 与库内其他书的关系。

## B · 外文科精读（1–2 万字，体例同 C）

适合外文书。**不留翻译稿**：通读原文后，**直接产出中文精读**（体例与篇幅同 C）。

两处差别：

1. 正文里**关键概念做特殊标注并附原文单词**：`**象征交换**（échange symbolique）`
2. **结尾附「关键概念对照表」**：中文术语 ← 原文单词（标首次出现位置）

## C · 万字精读（1–2 万字）

**跨章重组**，不按原书顺序。结构：

1. 这本书在回答什么问题（问题意识）
2. 3–6 个核心论题，每个论题跨章节取材，含：主张 → 论证链 → 关键原文 → 该论题的软肋
3. 作者的思想资源与对手
4. 与库内其他书的对照
5. 未解决的问题

## D · 逐章精读（每章 5000–6000 字）

按原书顺序，**每章一篇整体总结**，不作逐段解读。

单章结构：
1. 本章要解决什么
2. 论证的推进（从头到尾的一条线，有逻辑性、有整体性）
3. 关键原文（**斜体嵌在行文里，不单开一段详解**）
4. 本章的软肋与遗留问题（**一行**）

流程：先纵览全书 → **先写第一章交用户校准** → 确认后一口气完成其余 → 最后写总结回应。

## E · 换视角重写（每部分 6000–8000 字）

**E 不是“把书分成几段总结”，而是“换一套视角把这本书重写一遍”。**

用于原书篇章不适合做总结的情形：章节太碎或太长，或**值得写的东西不在原书的结构里**。E 要换维度重新组织全书，例如：

- **思想史脉络**——作者的立场、概念、方法如何分期演变（早期／转折／晚期）
- **思想大转折**——某个关键断裂点前后，问题与答案如何整体改写
- **自选切入维度**——只要是能重新照亮全书的一条线

**分段依据来自“重新叙述的维度”，不是原书目录。** 原书自带分期可用，但属例外。

**流程**：通读全书 → **先给出 2–4 个重写方案**（用哪条维度、切几部分、每部分处理什么）→ **等用户选定再动笔** → 每部分 6000–8000 字。

**体例同 D**：每部分一篇整体总结，一条逻辑连贯的叙述线；原文斜体内嵌；部分末尾一行遗留问题。

**常用重写维度（预设菜单，不限于此）**

给方案时从下面几条里挑，或提出新的：

1. **思想分期**——作者立场、概念、方法的分期演变（早期／转折／晚期）｜例：施米特从魏玛决断论到战后《大地的法》
2. **转折点**——某个关键断裂前后，问题与答案如何整体改写｜例：鲍德里亚 1976 年与马克思主义决裂前后
3. **概念史**——追踪**一个**核心概念在全书中含义的位移｜例：Nomos 在《大地的法》里如何从“取用”变成“秩序与场域的统一”
4. **论敌地图**——按“作者在跟谁斗”组织，每一部分是一次论战｜例：罗姆巴赫对黑格尔、对卢曼；德勒兹对黑格尔与弗洛伊德
5. **概念对子的张力**——全书由几组二分支撑，按这些对子重排｜例：公／私、内容／表达、奠基／拒绝、要素／环节
6. **层次重排**——微观到宏观（个体／互动／制度／世界体系）｜例：《现实的社会建构》天然如此；若原书不如此，可用这条轴重排
7. **沉默与回避**——按“作者不说什么、绕开谁”重排（最硬核，也最容易出新判断）｜例：齐泽克全书几乎不正面处理福柯
8. **概念的可迁移性**——把书中概念按“今天能解释什么”重排｜例：儒法国家 → 当代国家能力讨论

**判准**：一条好的重写维度必须能回答“**为什么这些内容要放在一起**”，而且在原书目录里**看不出来**。若它只是原书章节的换名，那不该用 E。

给方案时，每个方案要写明：**用哪条维度 → 依据是什么 → 它让什么原本看不见的东西显形**。

**读入动作**：**深思型**——A–E 里最深的一档。因为不循原书结构，读的时候就要把文本分解为可重组的材料。

**D 是顺序的**（跟原书章节），**E 是重构的**（另立一条线）。

## 附 · 概念卡（核心术语的落点）

预读时找出的核心术语，产出物就是**概念卡**：

| 项 | 标准 |
|---|---|
| 每本书的卡数 | **≤ 25 张**（核心概念，不是“重要概念”） |
| 定义 | **≤ 500 字**，必须自足（脱离原书也能被理解） |
| 关键原文 | 引足——原文是卡片的命 |
| 只做什么 | **名词解释**——判断与交锋不写进卡片 |

卡片文件不带 YAML frontmatter（避免被索引脚本误计为独立书籍）。

## 论文

A 单篇笔记／B 文献综述（多篇同议题）／C 深度解读／D 逐节精读。
按原文体量分档：<10 页 → 轻量档；10–20 页 → 中档；**>20 页 → 6000 字起**。
